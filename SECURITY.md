# Security policy

apxchol reads matrix, right-hand-side and saved-solver files, so a crafted
file is the most likely attack surface. Please report a suspected
vulnerability privately through GitHub: on the repository's Security tab,
choose "Report a vulnerability". Do not open a public issue. Include the
apxchol version, how you built or installed it, and a file or steps that
reproduce the problem.

Fixes go into the next release; only the latest release is supported.
